# Simple Interest Calculator

## Project Description

The Simple Interest Calculator is a simple project that calculates
the simple interest based on the principal amount, annual rate of
interest, and time period entered by the user.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

Where:
- Principal: The initial amount of money.
- Rate: The annual rate of interest in percentage.
- Time: The time period in years.

## Features

- Calculates simple interest.
- Uses principal, rate, and time as inputs.
- Provides a simple Bash-based calculator.

## Usage

Run the `simple-interest.sh` script in a Bash terminal
and enter the requested values.
